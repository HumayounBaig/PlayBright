Privacy policy

Effective date: 10 November 2026

Playbright runs on your device. It has no accounts and no analytics, and it does not send anything to any server, including your browsing activity, video content or page contents.

What is stored

Playbright keeps the following only in chrome.storage.local, on this browser:

  • for each site, whether Playbright is enabled;
  • for each site, the overlay reduction level;
  • for each site, selectors for the player elements you chose to hide with the picker;
  • your saved presets (a name and a reduction level).

This data never leaves your browser. The developer cannot see it.

What it reads on pages

To find overlays, Playbright reads the structure and styles of page elements around a video. It never reads video pixels, and it does not store or transmit what it reads. On pages without a video it stays idle.

No remote code, no third parties

All code ships inside the extension. It does not load or run remote code, and it uses no analytics, advertising or tracking services.

Tip link

The popup can show an optional tip link. Clicking it opens an external page in a new tab. The extension sends nothing to that page. That page is run by a third party under its own privacy policy.

Permissions

  • storage: saves your per-site settings and presets in this browser.
  • activeTab: lets the popup talk to the tab you are looking at when you use it.
  • commands: lets the Alt+Shift+Y keyboard shortcut toggle Playbright on the current site.
  • Access to all sites: the overlay can appear on any streaming site, so Playbright has to be able to run on any page to look for a video. It uses that access only to find and fade overlays and to hide elements you picked.

Chrome Web Store Limited Use

Playbright does not collect or transmit user data. Any information it handles locally is used only to provide the single purpose described above. It is not sold, not used or transferred for advertising, creditworthiness or lending, and not read by humans. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Deleting your data

Use Reset hidden elements for this site in the popup to clear hidden elements, delete presets in the popup, or remove the extension to delete everything it stored.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
