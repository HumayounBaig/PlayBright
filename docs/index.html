Watch the video, not the scrim.

Playbright is a free Chrome extension that fades the dark overlays and scrims that streaming sites draw over paused or idle video. Slide from the original look to fully removed.

Install

Coming soon to the Chrome Web Store. Meanwhile, load it unpacked from GitHub.

What it does

  • Fades dark overlaysFinds dark, video-sized scrims and gradient layers on streaming video and turns them down.
  • Original to removed sliderPick any level from the original appearance to complete removal.
  • Per-site on/offEnable it only where you want it. Settings are remembered for each site.
  • PresetsSave named reduction levels and apply them in one click.
  • Keyboard shortcutPress Alt+Shift+Y to toggle the current site. You can change it at chrome://extensions/shortcuts.
  • Click-to-hide pickerClick any player control or panel to hide it on that site. Press Esc to cancel.
  • Idle without videoOn pages with no video it does nothing, so regular sites are unaffected.

Free, local, private

Playbright is free. It runs entirely in your browser, has no account, and collects no data. Settings stay in Chrome's local extension storage. Read the privacy policy, or the support page if something is not working.
